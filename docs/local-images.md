# ローカルの図を読む

本筋の中に図を置くには、メインの Claude や Codex がすでに取り出した画像を、今回の作業フォルダの `images/` 直下に置きます。例：`images/figure-0001.png`。本筋や推敲ノートに `![図の説明](images/figure-0001.png)` と書くと、その場所で図を読めます。

**別に作った Codex の画像を見るだけ**なら、画像を用意したあと、推敲ノートの「ローカルの図」→「図を追加」でファイルを選びます。元のファイル名やパスを渡さず、使い捨ての作業フォルダに画像だけをコピーします。一覧には新しい名前を表示します。その相対パスをノートの Markdown にも使えます。ほかのアプリで画像を追加したときは「一覧を更新」を押してください。

- PNG・JPEG・WebP のみ。1件4 MiBまで、`images/` は32項目までです。拡張子やアップロード時の MIME と画像の先頭の識別子を照合します。ファイル名は拡張子を除き1〜80文字の半角英数字・`_`・`-`（先頭は英数字）、拡張子は小文字の `png`・`jpg`・`jpeg`・`webp` を使ってください。
- 図のフォルダを安全に開ける macOS・Linux が対象です。SVG・リンク・サブフォルダ・絶対パスは読みません。作業場所の外を探したり、Codex の出力履歴を自動で集めたりしません。
- 閲覧したことが外部サイトに伝わらないよう、本筋・付箋・ノートの Markdown や HTML に書かれた外部画像は自動で表示しません。ローカルサーバーから認証ヘッダ付きで図を受け取り、ブラウザ内だけで表示します。画像 URL に合言葉は付きません。
- 図の一覧・追加・表示ではモデルを呼びません。ImageGen を有効にしたり、質問・画像を生成サービスに送ったりしません。元画像のファイルは変更せず、作業フォルダのコピーはフォルダと一緒に破棄します。Markdown の書き出しに画像そのものは含みません。
