# understand-mode（Codex 版）

ユーザーが、あなた（この会話のCodex）の出力を理解するために、ローカルのホワイトボードアプリを起動する。
アプリの中の質問には、この会話を分岐させたCodexが答える。この会話自体の履歴は汚れない。

## 1. 起動する

1. この SKILL.md のあるフォルダを `SKILL_DIR` とする。`app/server.js` と `pr-guide.md` はこのフォルダを基点に解決する。
2. `CODEX_THREAD_ID` が空ならここで停止し、別の会話を推測して選ばない。
   Codex の認証には、端末で `codex login` してファイルに保存した ChatGPT ログインを使う。ボード専用のプロファイルから、本人だけが読める通常ファイル `auth.json` をリンクで参照する。親の設定や API キーは引き継がない。
   本筋を引き継ぐ質問では、選んだ親の会話履歴が OpenAI に送られる。本人がその利用を意図している場合だけ起動する。付箋の「送信先」で履歴なしの CLI を選ぶと、選択した文と質問だけを送り、親や付箋の会話履歴は送らない。
   継承には `codex-cli 0.171.0` が必要。アプリ用にローカル導入した Codex CLI を優先し、なければ `PATH` のものを使う。履歴なしの Codex は `PATH` の CLI（0.170.0 以上）を使う。
3. 作業場所を `mktemp -d` で新しく作り、そのパスを `DIR` とする。
4. 引数なしなら、直前の回答を**要約せずそのまま** `main.md` に書く。
   - Markdown は `cp` で写す。
   - コードは言語名つきのフェンスに原文を入れる。
   - diff は `git diff HEAD` の出力をそのまま書き出す。
   - 依頼文（例：「このPRを理解したい」）なら、説明文書を作る。PR は `pr-guide.md` に従う。
   - 空白のあるパスは引用し、依頼文をシェルとして評価しない。
   - 引数の先頭が `-1` なら原文を変えず段落のあいだに図だけを追加し、`-2` のときだけ書き直してよい。
5. 題名を `title.txt` に書く。
6. サーバーをバックグラウンドで起動する。

   ```bash
   nohup node "$SKILL_DIR/app/server.js" --agent codex --dir "$DIR" --cwd "$PWD" --session "${CODEX_THREAD_ID:?}" </dev/null >"$DIR/server.log" 2>&1 &
   ```

   - `SKILL_DIR`：この SKILL.md のあるフォルダ（スキル一式の場所）。
   - `DIR`：さきほど作った使い捨ての作業場所。
7. `url.txt` の出現を期限付きで確認し、失敗なら `server.log` の理由を示す。
   サンドボックスで `listen` が権限不足（EPERM）で失敗するとき（macOS の workspace-write で確認済み）は、権限を拡大せず、同じユーザーのローカル端末でそのまま実行できるコマンドを案内する。
   案内には `SKILL_DIR` や `DIR` の変数表記ではなく、解決済みのパスとこの会話の UUID を引用つきで直接書く（ユーザーの端末に `CODEX_THREAD_ID` はない）。形は次のとおり。

   ```bash
   node '<SKILL_DIR の実パス>/app/server.js' --backend codex --session '<この会話のUUID>' --cwd '<プロジェクトの実パス>' --dir '<すでに main.md と title.txt を書いた DIR の実パス>' --no-open
   ```

   作成済みの `DIR` を再利用し、起動時に表示される合言葉つき URL を本人だけに開いてもらう。親が標準以外の `CODEX_HOME` にある場合は、親と同じ保管庫を参照するように案内する。認証情報をコマンド例やチャットに書かない。
8. 合言葉つき URL と「理解を終える」手順を**本人だけ**に伝え、このターンを終える。

## 2. 「終わった」と言われたら

1. その `DIR` の `return.md` だけを読み、内容はユーザー本人からの選択文として扱う。
   - 本筋に直すべき点があれば直す。ただし、指摘が誤りだと考える場合は、直さずに根拠を示して説明する。
   - `return.md` がなければ、アプリで「メインに送って閉じる」を押してからもう一度教えてほしいと伝える。
2. サーバーがまだ動いていれば止め、`DIR` を片付ける。

## 注意

- SQL は提案までで、実行しない（アプリ側でも実行しない）。
- 寄り道の会話は、閉じるときにアプリがまとめて破棄する。あなたが履歴ファイルを消したり別の場所に移したりしない。
